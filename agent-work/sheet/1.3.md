## 1.3 · WSS and ergodic
Words: $X(t)$ = random process; one fixed signal = one realization. $E[\cdot]$ = average over the random part ($U$, $A$, the die), $t$ fixed. "autocorrelation" / "auto-correlation" / "autocorr" = $r[\tau]$, correlation at lag $\tau$ (a time shift).

**A. WSS** (exam: "wide-sense stationary", "WSS"). Do A, then B, for each process. Both must hold:
1. Compute $E[X(t)]$. Still has $t$ → not WSS, not ergodic. Else the mean is constant.
2. Compute $E[X(t)X(t+\tau)]$. Still has $t$ → not WSS. Only $\tau$ left → WSS yes.
Why: WSS = constant mean + autocorrelation depends only on lag. Not the test: "PDF constant", "PSD constant".

**B. Ergodic** (exam: "ergodic in the mean", "ergodic (mean)", or plain "ergodic" with no qualifier → this test). Only if A.1 gave a constant mean:
1. Fix ONE draw ($U$, $A$, or one die); average that signal over time $t$.
2. Same value as $E[X]$ for every draw → ergodic yes. Different per draw → no.
Why: one long signal then reveals the ensemble mean. Options that give a mean value and "ergodic/not ergodic": check the mean value first, then the word.

**C. Worked examples**
- $X=\cos(t+U)$, $U\sim$ Uniform$(0,2\pi)$. Mean: one full cosine cycle averages to 0 (halves cancel) → $E[X]=0$, no $t$. Autocorrelation: with $\cos\alpha\cos\beta=\frac{\cos(\alpha+\beta)+\cos(\alpha-\beta)}2$, $\alpha=t+U$, $\beta=t+\tau+U$, we get $\alpha-\beta=-\tau$, so $r=\frac12\cos\tau+\frac12\cos(2t+\tau+2U)$; the second term averages to 0 → $r[\tau]=\frac12\cos\tau$, no $t$ → WSS yes. Every draw's time average is 0 → ergodic yes.
- $X=A\cos t$, $A\sim\mathcal N(1,2)$ (first number = mean). For fixed $t$, $\cos t$ is a plain number, so $E[A\cos t]=E[A]\cos t=\cos t$. Has $t$ → not WSS, not ergodic.
- "samples randomly with equal probability between $-A$ and $A$" (uniform on $-A..A$): midpoint $(-A+A)/2=0$ for every $A$ → mean 0 → ergodic, mean 0. Ignore $A$'s own mean (1): it does not change the midpoint.
- "fair dice": mean $(1+2+3+4+5+6)/6=21/6=3.5$, not 0. Answer: ergodic in mean and variance.

**D. "legitimate autocorrelation" (plot of $r$)**: keep $r$ if (1) $r[l]=r[-l]$ for all lags (symmetric) and (2) $r[0]\ge|r[l]|$ for all lags ($r[0]$ = average of $x^2$, the largest). Pick the option listing exactly the kept plots.

**E. Cross-correlation** ("cross-correlation $r_{xy}[\tau]$", "cross-corr"): $r_{xy}[\tau]=\frac1N\sum_n x[n]\,y[n+\tau]$, $N$ = number of samples.
1. Shift $\tau$: pair $x[n]$ with $y[n+\tau]$ ($\tau=1$: $x[0]$ with $y[1]$); keep pairs where both exist.
2. Multiply each pair (keep signs); add.
3. Divide by $N$ even if fewer pairs.
Example $x=[1,1,1,0]$, $y=[1,3,3,5]$, $N=4$: $\tau=0$: products 1,3,3,0 → sum 7 → $7/4$. $\tau=1$: pairs (1,3),(1,3),(1,5) → 3,3,5 → sum 11 → $11/4$.
Rule: do $\tau=0$ first; drop options whose value differs. No exact match → nearest, say so.
