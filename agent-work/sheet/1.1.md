## 1.1 · Bayes word problems (counts)
Use when groups (machines, scanners, students, patients) come with counts or shares, a rate inside each group, and a probability is asked. Pdf or density given → not this (use 1.2/2.1).

**Recipe** (the reason for each step is in brackets)
1. **Total.** Counts given → items = those counts, total = their sum. Only percentages → pretend total = 1000 (1 000 000 if a rate is tiny, like 0.0005). [The answer is a ratio, so any total works.]
2. **Items$_k$** = share$_k$ × total. [Share = % of all items that belong to group $k$.]
3. **Pick "bad".** Bad = the event asked, or the event after "given / if / found to be / has had / has passed / positive". [Bad is the pile we count.] Asked NOT pass with a pass rate given → bad rate = 1 − pass rate. Asked pass → bad rate = pass rate, no subtraction (trap).
4. **Bad$_k$** = bad rate$_k$ × items$_k$. [2 % of 400 = 0.02 × 400 = 8 bad items.]
5. **$P(\text{bad})$** = (sum of all bad$_k$) / total. [Items are mixed at random, so a random item is bad with probability all-bad ÷ all-items.]
6. **$P(k\mid\text{bad})$** = bad$_k$ / (sum of all bad). [Given bad, only the bad pile is left; divide by the pile, not the total.]

**Wording** (exam word → same step here; a different word is a different step)
- defective, fail, NOT pass, positive, infected, ill, has TB, actually present → bad (asked or given). pass, sufficient quality, good → the good event.
- ill = infected = has TB = actually present. healthy = not infected = not present. "+" = positive.
- "false positive 3 %" = 3 % of healthy people test positive. "detects 95 % when present" = 95 % of ill people test positive. "99 % accurate" = 99 % of ill and 99 % of healthy classified right.
- "scans / paints N patients or cars" = count N. "mixed at random" = step 5.

**Ex 1 · machines (jun26).** M1 40 %, M2 35 %, M3 25 % of chips; defective 2 %, 4 %, 5 %.
- 1000 chips → 400, 350, 250 chips.
- Defective: 400 × 0.02 = 8; 350 × 0.04 = 14; 250 × 0.05 = 12.5. Pile 8 + 14 + 12.5 = 34.5.
- P(defective) = 34.5 / 1000 = **0.0345**.
- "Defective, from M2" = given bad → 14 / 34.5 = **0.41**.

**Ex 2 · CT scanners (apr25), NOT pass.** Scans 18, 22, 15 patients, one image each → images 18, 22, 15, total 55. Sufficient quality 85 %, 90 %, 66 %.
- NOT pass → bad rates 1 − 0.85 = 0.15, 0.10, 0.34.
- Bad: 18 × 0.15 = 2.7; 22 × 0.10 = 2.2; 15 × 0.34 = 5.1. Pile 10.0.
- P(NOT pass) = 10.0 / 55 = **0.18**. Bad image from CT2 = 2.2 / 10.0 = **0.22**.

**Ex 3 · disease (apr24) and virus (pe21).** Disease 0.0005, test "99 % accurate": 1 000 000 people → ill 0.0005 × 1 000 000 = 500; healthy 999 500.
- Ill positive: 0.99 × 500 = 495. Healthy positive: 0.01 × 999 500 = 9995. Pile 10 490.
- P(ill | positive) = 495 / 10 490 = **0.047** (exam "Pr[TB]").
- Virus 1.8 %, detects 95 %, false positive 3 %: 1000 → infected 18, not infected 982. Infected positive 0.95 × 18 = 17.1; not-infected positive 0.03 × 982 = 29.46; pile 46.56. 17.1 / 46.56 = 0.367 → **37 %** (b).

**Ex 4 · table (jan25).** Rows Male, Female; columns Engineering, Life Sciences, Literature, Psychology; grand total = all 8 cells = 200.
- "Given psychology, female": bad = psychology column = 10 + 26 = 36; female-psychology cell = 26. 26 / 36 = **0.72**.
- "Probability of Engineering" (no "given"): Engineering column 45 + 22 = 67; 67 / 200 = **0.335**.

**Ex 5 · lifetime (apr24).** $\Pr[T\ge t]$ = probability still working at year $t$. "Still working after 2, breaks in year 3" = given $T\ge 2$. Still working at 3 among those working at 2: $e^{-3/5}/e^{-2/5} = e^{-3/5+2/5} = e^{-1/5} = 0.8187$ (calculator). Breaks in year 3 = 1 − 0.8187 = 0.18 → **(d)**. [Dividing powers of e subtracts exponents. Exam "t ≤ 0" means t ≥ 0.]

**Ex 6 · experience (jan22).** S = satisfactory 75 %; S$^c$ = not S = 25 %. Experience given S 80 %. "No experience" given S$^c$ 15 % → experience given S$^c$ = 1 − 0.15 = 0.85.
- "Hired with experience, unsatisfactory": bad = experience. S 750 → 600 experienced; S$^c$ 250 → 212.5 experienced. Pile 812.5.
- P(S$^c$ | experience) = 212.5 / 812.5 = 0.26 → **(c)**.

**Yes/no and independence.**
- "statistically independent" ⇔ P(A|B) = P(A) ⇔ P(A∩B) = P(A)·P(B). Option "P(A|B) = P(A)" → always true.
- P(A∩B) = 0 means disjoint, not independent (unless a probability is 0).
- P(A or B) = P(A) + P(B) only for disjoint events. 50 % + 25 % = 75 % needs no overlap → F.
- "Bayes theorem is obtained from the total law of probability and the conditional probability" → F (key).
- "relative frequency tends to the probability mass function (pmf)" → T. pmf = P(X = x) for each value x.
- "CDF is 0 at −∞ and 1 at ∞" → T. CDF(x) = P(X ≤ x): nothing is ≤ −∞, everything is ≤ ∞.
- "Wiener FIR 1-step prediction … moving-average (MA) spectral estimation" → F: gives all-pole AR, not MA.
